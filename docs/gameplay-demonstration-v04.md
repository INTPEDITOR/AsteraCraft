# v0.4 실제 플레이 자동 조작 시연

`AsteraCraft-v0.4-gameplay.gif`는 실제 Godot 게임으로 진행한 7분 경기에서 채취·건설·생산·교전 구간을 골라 만든 90초 하이라이트다. 재생 속도는 3배이며, 480×300 해상도·초당 5프레임의 무음 GIF다. 플레이어 시야로 저장된 리플레이를 다시 촬영하면서 교전을 볼 수 있도록 카메라만 조정했다.

플레이어는 바위너구리 종족, 상대는 보통 난이도 귤 군체 봇이다. 황철 분지에서 고정 재현 시드 `2026101571`, 시작 슬롯 `[0,2]`로 진행했다. 플레이어의 `bot`은 계속 `false`였으며 정비공 4기·아스 50·테라 0으로 시작했다. 시연 스크립트가 실제 `main._send_command()`를 통해 채취, 일꾼 생산, 건설, 사수·의무병 생산, 최대 12기씩 공격 이동을 보냈다. 자원 증액, 유닛 생성, 즉시 생산, 시야 해제는 사용하지 않았다.

진행 순서는 정비공 8기 확보 → 보급창고 → 전투병영 → 정제소 → 야전의료소 → 병영 추가 → 사수·의무병 분대 → 공격 이동이다. 첫 공격 이동은 경기 3분 34초, 첫 교전 처치는 4분 11초 표본에서 관측됐다. 의무병 기술을 먼저 준비한 보수적인 시연 빌드이며 최적 경쟁 빌드를 의미하지 않는다.

7분 시점에 플레이어는 사수 25기·의무병 4기를 보유했고 처치 수는 37 대 1이었다. 상대 봇은 아스 1,943과 테라 446을 보유한 채 유닛 1기가 남았다. 봇의 자원 활용과 본진 방어에 개선 여지가 보였지만, 한 지도·한 시드·한 조합의 경기만으로 종족 전체의 밸런스를 결론 내릴 수는 없다. 경기는 7분에서 촬영을 종료했으며 승패가 확정되지 않았다.

동반 파일은 원래 게임 형식의 `AsteraCraft-v0.4-gameplay.acr`, 10초 간격 상태와 정상 명령 목록을 기록한 `playdemo-v04.json`, 초기 조건·자원 보존·인구·생산·실제 교전·리플레이를 검증한 `playdemo-audit.json`이다. ACR을 `user://replays/`에 넣으면 게임의 리플레이 목록에서 볼 수 있다. 기본 Windows 경로는 `%APPDATA%\Godot\app_userdata\아스테라크래프트\replays\`다.

재현 도구는 `tests/playdemo_v04.gd`, `tools_run_playdemo.js`, `tests/playdemo_highlights.gd`, `tools/encode_playdemo_gif.js`다. `playdemo_audit.gd`는 저장 결과를 별도로 읽어 확인한다. 이 시연은 실제 인터넷 멀티플레이, 장시간 성능, 여러 경기 승률의 검증을 포함하지 않는다.
