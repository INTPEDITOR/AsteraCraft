아스테라크래프트 v0.5.5 / 2026-10-16

1. 제공된 투혼 1.4 / 파이썬 1.3 / 로스트템플 2.4 적용
SCM/SCX의 CHK 지형, 실제 플레이어 시작점, 광물/가스 좌표와 매장량을
data/original_maps.json에 변환하여 런타임·로비 미리보기·미니맵에 적용.
E:/StarCraft 설치의 Jungle CV5/VF4를 읽기 전용으로 추출하여 통행,
높이, 건설 가능 여부를 해석했다. Python owner 4~7 관전자 마커 제외.
원본의 비대칭과 섬 확장을 보존. 지형 텍스처는 AsteraCraft의 기존 그림.
경로 탐색은 기존 엔진의 32픽셀 칸: 16개 미니타일 중 13개 이상 통행
가능할 때 이동 허용, 16개 전부 통행 가능하고 CV5가 허용해야 건설 가능.
따라서 StarCraft의 8픽셀 충돌 판정과 완전히 같은 엔진은 아니다.
기존 리플레이에는 이전 독자맵을 불러오고 새 기록에는 맵 버전을 저장.
멀티플레이 프로토콜 7: 모든 참가자는 v0.5.5 사용.

2. 접목충 정신 조종
Q를 누른 뒤 보이는 적 유닛을 클릭. 에너지 100, 사거리 6, 재사용 20초.
최대 에너지 200 / 초기 100. 조종 성공 후 2초 노출, 이후 기존 은폐 복귀.
유닛 ID·종족·종류·체력은 유지하고 소유권, 시야, 인구수, 명령 권한 이전.
기존 명령/건설 계획/치유 대상을 해제. 시전자 사망 후에도 소유권 유지.
건물·배양체·탑승 유닛·승객이 있는 수송선·미탐지 은폐 유닛은 대상 제외.
조종한 타 종족 일꾼은 이동·채취·전투와 원래 수리 능력을 사용할 수 있지만
다른 종족 기술 트리를 건설할 수 없다. 서버에서도 동일하게 검증한다.
AI도 보이는 사거리 내 유닛에 사용하며 무한 에너지 등 혜택은 없다.

3. 건설 메뉴와 초상화
건물 아이콘에 마우스를 올리면 기존 정보칸에 아스/테라, 건설 시간,
선행 조건, 부족 사유, 건물 기능을 표시. 비활성 아이콘도 동일하게 표시.
초상화는 기존 칸에 전체 이미지를 맞춰 하단 잘림 방지.
HUD 전체 크기·각 칸의 위치·비율·검은 메뉴 버튼은 그대로 유지.

4. 양분 저장낭
2x2 점유 크기는 유지하고 얇은 과일 울타리 대신 큰 양분 주머니 세 개와
뿌리 받침이 있는 새 그림으로 교체. 실제 점유 칸을 충분히 채운다.
기본 도구로 생성, assets/building_1_02_nutrient_v053.png에 저장.
프롬프트는 docs/nutrient-sprite-v053-prompt.txt.
비행체 원화·방향 카탈로그는 변경하지 않았다.

5. 검증 및 알려진 한계
원본 맵 12개 시작점의 채취와 지상 연결, 정신 조종 권한/예외,
실제 Q 클릭, 건설 정보 표시, 초상화 42종을 확인.
새 맵에서 일꾼 생산으로 초기 전투 예산이 소진되는 AI 문제를 수정하고
종족×난이도 9개, 각각 240초 개막 시뮬레이션 통과.
외부 TTS 녹음 교체와 공개 인터넷 로비 배포는 이번 변경에 포함하지 않음.
장시간 경쟁 밸런스 검증은 별도.

[v0.5.5 추가]
군체모수 중심 12칸 이내 추가배양낭 생산 권한 통합. 군체모수 선택으로 연결된 배양체 생산·취소·집결 관리. 연결 소실 시 생성과 진행 중 변태 정지, 재연결 시 재개. 가장 가까운 완성 군체모수 자동 연결.
군체모수·뿌리중계체 중심 13칸 뿌리 지대를 지면에 표시. 군체모수를 제외한 귤 건물은 전체 건설 칸이 자신의 뿌리 지대 안이어야 함. 뿌리중계체도 기존 뿌리에 건설하며 완성 시 범위를 확장. 공급원이 파괴되면 해당 범위 소멸. 기존 건물 자체는 유지.
어택땅 시 시야·탐지·공격 대상·탐색 범위를 만족하는 적 중 아군을 공격 중이거나 최근 2초 내 공격한 적을 우선. 직접 지정 공격은 유지.
뿌리 지대 경계: 직선 테두리 제거, 불규칙한 외곽과 지면·절벽 경계 투명도 혼합. 건설 범위 판정은 유지.

[v0.5.5 수정]
원본 CHK 자원 좌표를 게임의 정수 타일 중심 기준으로 변환(-0.5칸). 자원 원본 좌표 source_pos 보관, 지형과 자원량·자원 순서 유지.
테라 정제 건물은 정확한 매장지 위에서 실제 광물 겹침만 검사하며 일반 건물의 0.2칸 채취 여백은 적용하지 않음. 같은 격자 안의 짧은 건설 접근 경로도 몸체 통과 검사로 허용.
세 맵 36개 테라 × 3종족 모두 일꾼 명령·접근·건설·추출 검증. 모든 12시작 위치 ×3종족에 본진 아래 일꾼4명 가로 대기 시작. 자동 채취 시작은 하지 않음.
일꾼 광물 접근 위치를 실제 경로 길이로 비교. 직선 통과 가능 시 직접 이동, 불필요한 경유점 제거, 막힌 접근 지점 재탐색.
채취 명령 중 일꾼은 이동·반납 중 다른 유닛과 충돌하지 않음. 지형·건물·자원은 통과 불가. 채취 명령 종료 시 일반 충돌 복원.
