# 자원 규격 기준

1. BWAPI 공식 소스의 `UnitType.cpp`에서 광물 3종의 점유 규격은 2×1타일, 가스와 세 종족 정제 건물의 점유 규격은 4×2타일입니다. 한 타일은 32픽셀이며, 자원의 충돌 외곽은 광물 64×32픽셀·가스 128×64픽셀입니다. 이 규격을 아스·테라의 논리 충돌과 배치 기준으로 사용합니다. 생성 이미지의 높이와 돌출부는 바닥 점유 영역과 구별합니다.
   https://github.com/bwapi/bwapi/blob/main/bwapi/BWAPILIB/Source/UnitType.cpp
2. Blizzard 공식 자원 안내는 자원을 클릭하면 선택 정보에서 남은 양을 확인하고, 광물 한 덩어리에는 한 일꾼만 채굴하며 다른 일꾼은 기다리는 방식을 설명합니다. 아스는 이 규칙을 따릅니다.
   https://classic.battle.net/scc/gs/res.shtml
3. 아스테라크래프트는 테라를 정제 건물 완성 후 3초마다 8씩 자동 채취합니다. 이는 이 게임의 별도 규칙이며 스타크래프트의 가스 일꾼 배치 방식을 재현한 것은 아닙니다. 매장량이 0이면 생산이 멈춥니다.
4. 자원 이미지·클릭 범위·길 찾기 충돌은 같은 자원 위치를 기준으로 계산합니다. 정제 건물은 테라 매장지의 정확한 타일 앵커에만 건설합니다.
5. 세 독자 전장은 가로로 긴 자원의 점유 영역까지 네 출발점에서 대응하도록 좌우·상하 반사 대칭을 사용합니다. 공정한 배치는 종족 사이의 실전 밸런스 검증과 별도로 관리합니다.
6. 기본 매장량은 아스 한 덩어리 1,500, 테라 한 매장지 5,000입니다. 각 본진은 아스 8개와 테라 1개로 시작하며, 아스 합계는 12,000입니다. 이는 매장량이며 시작 시 플레이어가 소유한 자원과는 다릅니다.
