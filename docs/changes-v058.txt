아스테라크래프트 v0.5.8 / 2026-10-18

공개 인터넷 매칭
- 게임 내부 로그인·래더 대기·커스텀 방 목록·준비·관전을 공개 HTTPS 서비스에 연결.
- 공개 서비스는 계정, 방, Elo, SDP/ICE 연결 정보만 처리. 전투는 방장 PC에서 실행한 별도 headless 게임 프로세스가 권한을 가짐.
- native WebRTC 직접 연결. STUN 사용, TURN/전투 중계 없음. 엄격한 NAT나 방화벽 환경에서는 실패할 수 있음.
- 매칭 확대, 준비 완료 후 5초 대기와 마지막 3초 잠금, 관전자 명령 제한, 참가자 결과 일치 및 중복 점수 방지.
- 연결 실패·방장 종료 시 무효 처리. 전투 재접속 및 부정행위 방어 강화는 후속 과제.
- 서버 자동 검사 82건 통과. 방장 퇴장 시 관전자가 아닌 참가자에게 승계하며 참가자가 없으면 방을 닫음. 공개 HTTPS URL을 이용한 같은 PC 방장·게스트·관전자 통합 검증 통과. 서로 다른 인터넷 회선 간 검증은 미실시.

맵 표현
- 실제 192×96 마름모 메시를 어긋나게 배치하고 가장자리를 20% 겹쳐 연결. 이전 128×64 대비 1.5배.
- 동일 지형은 동일한 색과 재질을 사용하고, 공통 좌표로 질감을 읽어 타일 경계·색 얼룩·반복 테두리를 제거.
- 평평한 바닥의 디테일을 줄이고 별도 투명 장식 36종(지형당 12종) 추가. 풀, 덤불, 돌, 가지, 폐벽, 기둥, 잔해 등을 무리 지어 배치.
- 원본 세 맵 지형·높이·자원·시작 위치·이동 충돌은 유지. 장식은 자원, 시작 지점, 경사로를 피하고 큰 구조물은 통행 불가 지형에만 배치.
- 승인된 HUD 비율과 비행체 방향 그림은 변경하지 않음.

이동과 규칙
- 대형 유닛은 반 칸 단위 몸체 여유를 검사해 2칸 입구와 꺾이는 통로를 통과. 모서리를 일찍 건너뛰어 벽에 끼는 현상 수정.
- 근접 접근 후보의 도달 경로를 비교하고 접근 자리 재탐색을 제한해 밀집 전투 부하 감소.
- 채취 일꾼과 함께 건설 이동·건설 중 일꾼도 유닛 충돌을 무시. 지형·건물·자원 충돌은 유지.
- 부엉이 종족은 자신의 완성된 인구 탑 12칸 범위 내에 건설. 탑 자체는 범위 제한 예외. 건물 전체 면적 기준이며 AI도 탑을 먼저 건설.
- 테라 채취 8개 주기를 3.5초에서 3.0초로 단축.
- 정지 그림 위주 비행체에 종족별 8프레임 이동 추진 효과 추가. 지상 걷기 및 차량 몸체 동작 검사.
- v0.5.7의 사용자 제공 메뉴·종족별 BGM 및 기존 생산·정신 조종·자동 채취 수정 포함.

검증과 남은 범위
- 이동 96, 충돌 107, 자동 채취 332, 테라 위치 792, 원본 맵·정신 조종 78, 군체·뿌리 26 검사 통과.
- 39종 동작 검사 68건, 장식 4,470건, 지형 메시/경계 약 550만 검사 통과. HUD·비행체 잠금 검사 통과.
- 400기 밀집 근접전 개발 빌드 측정: 평균 약 93ms, p95 약 168ms/시뮬레이션 틱. 출시 수준의 대규모 교전 성능이라고 판단하지 않으며 추가 최적화 필요.
- 장시간 네트워크·경쟁 밸런스, 호스트 신뢰 문제, 외부 TTS 교체는 남아 있음.
- 실제 내보낸 EXE/PCK/네트워크 DLL 검증 기록은 QA 폴더 참고.
