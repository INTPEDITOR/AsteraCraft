# 유닛별 단일 능력치 연구 제안

**이 소폭 증가안은 사용자 정정으로 제외했다. 최종 승인으로 구현한10종은 [확정 연구 데이터](passive-research-20261024.json)를 따른다.**

사용자 최종 조건: 복잡한 발동 조건 없이 능력치 하나를 올리는 연구를 유닛당1개만 둔다. 모두1회 연구이며 현재는 제안만 했다. 아직 게임 데이터에 연결하지 않았다. 별도 선행 건물이 없으면 실제 생산 건물에서 연구한다.

| 유닛 | 단일 효과 | 연구 건물 |
|---|---|---|
| 방패보병 | 방어력2→3 | 장갑연구소 |
| 야전의무병 | 체력75→90 | 야전의료소 |
| 추적미사일 차륜차 | 사거리5.9→6.4 | 기갑공장 |
| 장갑수송정 | 이동 속도10% 증가 | 항공격납고 |
| 덩굴포식자 | 사거리3.5→4.0 | 후피진화소 |
| 가시꽃 | 이동 속도10% 증가 | 과즙분비샘 |
| 접목충 | 체력45→60 | 군체신경핵 |
| 포낭비행체 | 방어력1→2 | 익막둥지 |
| 서약수호자 | 이동 속도10% 증가 | 서약전당 |
| 규율집행관 | 사거리5.2→5.7 | 천문관측소 |
| 고대석익병 | 이동 속도10% 증가 | 석익조형소 |
| 회랑지기 | 실드160→180 | 천공회랑 |

제안 표는 현재 game.json의 기본 수치를 대조했다. 중장갑/경장갑 추가 피해는 늘리지 않는다. 비용/시간은 적용 범위 확정 후 책정한다.
