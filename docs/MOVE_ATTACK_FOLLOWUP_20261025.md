# 이동·근접 공격 추가 수정 및 전차 고정 사거리 — 2026-10-25

현재 소스 수정과 로컬 실행 검증을 마쳤다. 기존 feedback8/0.6.2 다운로드에는 아직 포함되지 않았다. 앞선 이동 연속성 수정은 유지했다.

## 확인한 문제와 수정

- 수동 이동 명령 후에도 이전 자동 공격 대상과 포위 자리 예약이 남았다. 그 결과 후퇴 중인 유닛을 여전히 교전 중으로 분류해 정지 아군 우회를 생략할 수 있었다. 새 일반 명령이 들어오면 이전 교전/포위/막힘 상태를 해제하고 새 목적지에 맞춰 이동한다. 기술 사용은 기존 분기를 유지한다.
- 근접 공격의 접근 경로 계산이 한 틱의 예산 때문에 미뤄지면, 실제 접근 불가와 같은 0.65초 대기를 저장했다. 아직 계산하지 못한 경우에는 사용하지 않은 자리를 풀고 다음 계산 가능 틱에 재시도한다. 실제로 포위되거나 접근할 수 없는 경우의 재시도 간격은 유지한다.
- 자동 대상 탐색은 정확한 최대 사거리의 적을 제외했지만 발사는 해당 거리를 허용했다. 탐색 경계와 발사 경계를 맞췄다.
