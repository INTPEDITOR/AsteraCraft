# 가까운 광물 배치 v0.4

세 맵의 모든 본진과 확장은 8개 아스 광물을 본부 북쪽의 작은 말굽 형태로
배치합니다. 정수 기준 기지 중심에 더하는 좌표는 다음과 같습니다.

`(-5.5,-1), (-4.5,-3), (-2.5,-4), (-0.5,-4), (1.5,-4), (3.5,-4), (5.5,-3), (6.5,-1)`

광물 몸체는 각각 2×1칸이며, 전체 광물선은 14×4칸입니다. 실제 4×3칸 본부와
광물 몸체의 간격은 약 2.83~3칸이고, 안쪽 채취 통로는 3칸입니다. 옆으로
꺾이는 구간에도 일꾼이 통과할 수 있는 1칸 간격을 둡니다. 좌우·상하 반사는
광물의 가로 규격과 실제 본부 충돌 사각형을 그대로 보존합니다.

각 맵은 아스 96개×1,500과 테라 12개×5,000을 유지합니다. 테라 위치와 4×2칸
정제 건물 정렬, 지형·물·절벽·다리·입구·높이·건설 가능 영역은 바꾸지 않았습니다.

`node tools_make_maps.js`는 기존 지도 카탈로그의 광물 좌표와 배치 설명만
갱신합니다. 여러 번 실행해도 같은 결과를 만들며, 패키징 검증기가 생성 규칙과
`data/maps.json`의 일치를 확인합니다.

검증 결과:

- `tests/map_test.gd`: 22,107개 통과. 대칭, 자원 비겹침·총량, 모든 채취면
  접근성, 대형 유닛 이동 경로와 정제 건물 부지를 확인했습니다.
- `tests/compact_minerals_v04_test.gd`: 1,818개 통과. 3개 맵에서 종족 배치를
  세 번 회전하여 36개 본진을 실제 일꾼 12명으로 검사했습니다. 모든 광물 8개를
  사용했고, 40초 동안 본진별 768~832 아스를 반납했습니다. 전체 아스를 고갈시킨
  뒤에도 마지막 짐을 전부 반납하고 일꾼들이 유효한 충돌 위치에서 대기했습니다.
- 기존 코어 547개와 자원 스냅샷·밀집 채취 458개 검사도 다시 통과했습니다.

채취 검증은 경제 규칙을 확인하는 통제 실험이며, 정상 플레이 영상이나 전체
게임의 종족 밸런스 평가를 대체하지 않습니다.
