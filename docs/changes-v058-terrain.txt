아스테라크래프트 v0.5.8 지형 수정판 / 2026-10-18

사용자가 제공한 로컬 타일셋 자료의 구성 원리만 참고했습니다.
자료의 타일 이미지는 게임에 복사하거나 포함하지 않았습니다.

수정 사항
- 원본 맵의 이동 불가 판정과 시각적인 절벽 판정을 분리했습니다.
- 평지의 바위와 장식은 낮은 독립 오브젝트로 표시하며 가짜 지면 높이를 부여하지 않습니다.
- 절벽의 윗면에는 바닥 재질을 사용하고, 높이 경계의 옆면에만 절벽 재질을 표시합니다.
- 물가의 지면은 별도의 자갈 재질로 연결합니다.
- 192×96 마름모 타일을 겹침 없이 연결했습니다. 타일마다 달라지던 가장자리 투명도를 제거했습니다.
- 같은 지형의 질감 좌표와 재질 혼합값을 공유해 마름모 경계에서 색과 질감이 끊어지지 않게 했습니다.
- HUD 비율 및 승인된 비행체 이미지·시점을 유지했습니다.
- 원본 맵의 이동 가능 칸, 높이 판정, 건설 가능 칸, 시작 위치와 자원 배치는 유지했습니다.

기존 v0.5.8과 동일한 게임 버전이며 지형 표현 수정판입니다.
기존 배포 폴더와 ZIP을 덮어쓰지 않고 별도 폴더에 제공합니다.
이번 검증은 지형·원본 맵·HUD/비행체 유지와 실행 확인을 대상으로 합니다.
온라인 매칭과 대규모 전투 성능을 이번 지형 수정에서 새로 검증한 것은 아닙니다.
