# 하단 UI 구조 점검

1. 참고 자료는 Blizzard의 StarCraft 공식 Terran Basics 화면입니다. https://classic.battle.net/scc/terran/basic.shtml / https://classic.battle.net/images/battle/scc/terran/PICS/bbasic07.jpg
2. 왼쪽 미니맵, 중앙 선택 정보, 오른쪽 초상화와 명령창이라는 배치를 기준으로 삼았습니다. 바위너구리는 기존 `ui_hud_0.png`를 유지하고, 귤·부엉이는 낮고 넓게 다시 제작한 `ui_hud_1_native_v3.png`, `ui_hud_2_native_v3.png`를 일체형 틀로 사용합니다. 새 배너는 원본의 가로·세로에 동일한 배율을 적용하며 화면 하단에 정렬합니다.
3. 장식 위의 투명한 틈에는 실제 지형과 유닛이 이어져 보입니다. UI 몸체와 정보창 아래에서는 가림 처리하여 플레이 장면이 글자 뒤로 비치지 않게 합니다.
4. UI 몸체는 화면 좌우와 맨 아래까지 채웁니다. 원본 외곽선과 무관한 검은 사각 뒷판이나 반복 장식 테두리는 덧그리지 않습니다.
5. 명령은 원본에 이미 그려진 12칸 안에서 아이콘과 단축키로 표시합니다. 유닛 선택 최대 12기, 명령 슬롯 수, 아스·테라·인구의 설정은 아스테라크래프트 규칙을 따릅니다.
6. 작은 칸의 행동명은 툴팁으로 제공합니다. 메뉴는 원본의 얇은 메뉴 홈 안에 3선 기호로 표시하고, `Esc`와 클릭으로 엽니다.
7. 별도 팝업과 메인 메뉴 버튼은 실제 픽셀 크기의 생성형 PNG로 표시합니다. 팝업은 코너 비율을 유지하고 가운데 생성 질감을 반복해 각각의 규격으로 제작했으며, 실행 중 PNG를 가로로 늘리지 않습니다.
8. 새 종족별 재질 보드는 HUD 전체의 뒤쪽 바탕입니다. 초상화·정보·미니맵·명령 칸 위에는 덧씌우지 않고 원래 프레임과 창 표현을 유지합니다. 미니맵의 실제 지형·시야 안개도 기존처럼 그립니다.
