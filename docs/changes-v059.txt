아스테라크래프트 v0.5.9 — 2026-10-18

사용자가 선택한 A자 아스 결정 아이콘을 게임 창과 Windows EXE에 적용했습니다.
귤박쥐: 귤 껍질 몸통, 뿌리 꼬리, 녹색 귤잎 날개의 새 5방향/2프레임 스프라이트.
세 종족 초상화: 배경을 새로 제작하고 기존 HUD 안에서 얼굴을 확대 표시. 귤박쥐 초상화도 새 외형과 일치.
HUD 외곽 비율 및 다른 비행체 시점 유지.

뿌리: 안개 밝기를 타일별 단색 대신 공유 꼭짓점에서 연결. 미탐색 지면은 표시하지 않음.
뿌리 지형을 작은 구역별로 캐시하고 한 프레임당 최대 3구역/약 2ms 작업 단위로 분할. 변하지 않은 구역은 재생성하지 않음.
완성된 경계를 함께 반영해 갱신 중 사각형 작업 구역이 드러나지 않게 함. 성장이 끝난 뿌리의 반복 계산 생략.
주의: 시간 예산은 작업 단위 사이에서 검사하므로 프레임 전체의 절대 시간 제한은 아님. 모든 상황의 끊김 제거를 보증하는 것은 아님.

건설: 건물 좌측 위 칸 대신 발자국 중심을 마우스에 맞춤. 테라 채취 건물의 자원 위치 고정 유지.
귤 건물 건설 취소: 소모된 일꾼 1마리 복귀, 기존 체력/운반량 유지, 중복 취소로 일꾼/환불 중복 발생 방지.
부대 번호를 350ms 이내 두 번 누르면 선택 부대 중심으로 이동. 초상화 클릭 시 해당 대표 유닛/건물로 이동.
건물과 아스/테라 자원을 같은 지면 깊이 순서로 그려 겹침 순서 수정.

대기실: 방장도 관전 가능하며 계속 자신의 PC에서 경기를 호스팅. 관전자 방장 준비 및 결과 보고 허용.
버튼 권한/상태/설명 및 대기실 오류 표시 수정. 자유전 팀 변경, 꽉 찬 슬롯 추가, 없는 컴퓨터 제거 비활성화.
기존 공개 매칭 서버 업데이트 완료. 참가자 두 명+관전자 방장 클라이언트의 실제 WebRTC 경기/승패/참가자 전적 확인.
검증 범위: 같은 PC의 세 클라이언트와 공개 HTTPS 매칭 서버. 서로 다른 NAT 환경의 원격 PC는 이번에 시험하지 않음.

검증: 입력 49개, 대기실 20개, 귤 건설 취소 9개, 뿌리 성장/시야 9732개, 건물 안개 기억 11개 통과.
뿌리 1597칸/33구역의 분할 갱신 및 정지 상태 재생성 없음 확인. 세 맵 15장 화면 확인.
