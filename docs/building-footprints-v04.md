# 건물 규격 대조 v0.4

한 칸은 32×32 월드 픽셀입니다. 충돌·건설·선택에는 이 표의 실제 타일 크기를 사용하고, 그림은 원본 비율을 유지합니다.

기준: [BWAPI UnitType.cpp](https://github.com/bwapi/bwapi/blob/main/bwapi/BWAPILIB/Source/UnitType.cpp). 비교용이며 아트나 원본 맵은 가져오지 않았습니다.
