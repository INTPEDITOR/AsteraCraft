# E 드라이브 이전 스크립트 검토

`tools/Migrate-AsteraCraft.ps1`는 이전 준비용이며 자동 실행하지 않습니다. 현재 작업 환경에서는 E 드라이브 쓰기가 허용되지 않아 실제 복사·삭제를 실행하지 않았습니다.

목표는 `E:\Codex\AsteraCraft` 아래에 작업 폴더의 상대 구조를 보존하는 것입니다. 따라서 실제 Godot 프로젝트는 `E:\Codex\AsteraCraft\AsteraCraft`, 배포본은 `E:\Codex\AsteraCraft\deliverables`, 엔진은 `E:\Codex\AsteraCraft\tools` 아래에 놓입니다.

이전 대상은 명시한 `AsteraCraft`, `deliverables`, `tools`, `rts-references`, `outputs`, `work` 폴더와 루트의 게임 보조 스크립트 3개입니다. 관련 없는 `NVIDIA Corporation`, 기타 설정·전송 도우미 폴더 등은 선택하거나 지우지 않습니다. 로컬 이전은 공개 배포와 다르므로 게임 폴더 안의 로컬 자료와 체크포인트도 보존합니다.

기본 실행은 목록·용량만 보여 주는 **dry run**입니다. `-Copy`를 명시하면 모든 대상 파일의 SHA256을 계산하고 복사한 뒤 다시 비교합니다. 대상 위치에 다른 내용의 파일이 이미 있으면 덮어쓰지 않고 중단합니다. 심볼릭 링크·정션이나 경로 이탈이 있으면 중단합니다.

`-Copy -DeleteSource`를 명시한 경우에만 복사본·원본을 다시 검증하고, 파일 집합과 내용이 처음과 같을 때 명시된 C 원본 항목을 삭제합니다. 작업 폴더 전체를 재귀 삭제하지 않습니다. 삭제 전 모든 절대 경로가 원본 작업 폴더 아래인지 검사합니다. 검증 기록은 E 대상 폴더에 `migration-manifest-날짜.json`으로 저장합니다.

실제 이전은 게임·Godot·로컬 로비·파일을 쓰는 작업을 종료한 상태에서 수행해야 합니다. 실행 정책 변경이나 관리자 권한 실행을 강제하는 명령은 포함하지 않습니다. 현재 대화에서는 스크립트 준비와 구문 검사만 수행합니다.
