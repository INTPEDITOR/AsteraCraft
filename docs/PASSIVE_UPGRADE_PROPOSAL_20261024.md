# 저활용 유닛 보완 연구 제안

**아래 조건부 초안은 사용자 정정으로 제외했다. 최종 승인으로 구현한10종은 [확정 연구 데이터](passive-research-20261024.json)를 따른다.**

현재 역할·가격·선행 건물과 기존 스킬 연구를 대조한 초안이다. 실제 승률/선택률 자료가 없어 아래 유닛이 약하다고 확정한 것은 아니다. 새 패시브는 아직 게임에 적용하지 않았다.

유닛당1개를 기본으로 하고 지원 유닛 일부만2개를 제안한다. 공격력·중장갑 추가 피해를 한꺼번에 올리기보다 역할을 유지하면서 운용 불편을 줄인다. 모든 연구는1회이며 재연구/효과 중첩은 없다. 별도 생산 선행 건물이 있으면 그 건물에서 연구하고, 없으면 실제 생산 건물에서 연구한다. 표의 비용은 아스/테라, 시간은 게임 초다.
