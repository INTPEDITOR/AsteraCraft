아스테라크래프트 v0.6.0 구현·검증 기록
최종 정리: 2026-10-21 / 기준 배포판: v0.5.10
배포 파일과 최종 해시는 GitHub v0.6.0 Release 및 BUILD_MANIFEST.json을 참고한다.

게임 동작
- 연구 건물 전체에 5개 대기열, 개별 취소와 실제 지불액 환불 적용.
- 군체모수의 연결 배양체 선택, 배양체별 독립 동시 변태 적용.
- 완성 본진을 모두 잃으면 60초 안에 새 본진을 완성해야 하는 재건 규칙 적용.
- 창 이동 중 마우스 강제 이동, 혼합 부대 공격 이동, 몸체 중앙 선택, 부대/초상화 화면 이동 수정.
- 최근접 자원 FIFO 대기, 지역 자원 소진 시 본진 복귀·정지 적용.
- 규율탑 상실 시 부엉이 건물 비활성화. 본진·테라 건물·규율탑은 예외.
- 귤 뿌리는 외곽부터 역순으로 서서히 사라지며 미확인 뿌리/건물 정보는 노출하지 않음.
- 난이도별 AI 집결 공격과 가까운 확장, 방장 관전·컴퓨터 종족 변경·슬롯 닫기/열기 적용.
- 리플레이 저장 버튼 외 자동 파일 저장 제거, 기록/전송 부하와 비공개 상태 누출 보완.

유닛·연출
- 경/중장갑, 추가 피해, 가격·역할·주기, 연구 해금 기술과 낮은 시작 마나 적용.
- 모즙체: 시작 25/최대 200 마나, 자동 치유, 생명 환원, 주변 공격속도 +25% 개화 촉진.
- 접목충 아스 100/테라 150, 정신 조종 마나 200 적용.
- 화염돌파차·드론 모함(요격 드론 최대 8기)·성좌추격기, 공중 가속/감속 적용.
- 폭격기 8 피해 × 5연발, 이동요새 세 포신 0.22초 간격 3연발(총 기본 피해 40/중장갑 추가 8).
- 각 무기/능력 스프라이트, 종족별 사망, 45초 건물 잔해, 수송 승객 칸·개별 하차 적용.
- 핵 상승 4초+추가 유도 11초+낙하 3초, 작은 붉은 점과 종족별 경고, 32단계/16초 핵구름 적용.
- 3종 HUD 전체를 공통 비율로 재제작하고 프레임 내부 단일 메뉴 칸 적용.
- 종족별 다색 아이콘, 256×320 초상화, 귤 과육·초록 잎·청록 렌즈 스프라이트 적용.
- 빨간 십자가 제거. 실제 의무병 108개 동작과 의료 아이콘에 청록 표식 사용.
- 요격기·폭격기·요격 드론·이동요새 디자인 구분, 연관 아이콘과 드론 초상화 교체.
- 이동요새 모든 방향을 3연장으로 통일. 후면/앞면을 구분하고 각 포신의 발사점 순차 적용.
- 같은 유닛의 방향별 차체 크기·발 기준점을 등록하고 옆 칸 조각과 잘림 제거.

음성·효과음
- 유닛 44개 목소리 프로필과 종족 나레이션, 활성 265개 짧은 음성 적용.
- ElevenLabs 대사 195개, VARCO 새 귤 괴물·기계 반응 70개. 기존 SAPI 재생성으로 덮어쓰기 방지.
- 바위너구리 바리톤/강한 무전, 귤 유닛 괴물·기계음/낮은 여성 나레이터, 부엉이 남성/석상 공명.
- 승인된 여성 나레이션은 음색 유지/10% 빠른 말하기 적용.
- VARCO 효과 원본 20종을 편집·조합한 무기/스킬/수송/파괴 등 123개 재생 큐 적용.
- 원본 출처와 편집 기록은 관련 JSON 및 licenses/Audio-Credits.txt에 기록.

검증 결과
- 핵심 규칙/이동/채굴/전투 25개 검사 묶음 통과.
- 화면/버튼/입력/음성 20개 검사 묶음 통과.
- 마지막 변경 관련 10개 검사 묶음 통과. 이동요새/폭격기 연발 동작 44개 항목 통과.
- 음성 2,534개 검사, 효과음 618개 검사 통과.
- 스프라이트 방향·여백·기준점·규격 3,316개 검사 통과.
- 새 유닛 160프레임 전체의 여백과 분리된 잔여 조각 검사 통과.
- 원본 지도 246,132개 대조 검사 및 통행/절벽/채굴 회귀 검사 통과.
- 세 맵·세 종족 9개 20분 합성 장기전 검사 통과. 50/100/150/200기 단계 부하와 채굴 지속 확인.
- 5연발 추가 후 바위너구리 20분 추가 검사 통과. 200기 구간 시뮬레이션 평균 24.27ms/p95 31.74ms.
- 위 수치는 헤드리스 합성 시뮬레이션이다. 화면 렌더링을 포함한 실전 FPS나 다른 PC의 성능 보장 수치가 아니다.
- 배포 파일 검사, 실제 EXE 부팅, WASAPI 음악 재생과 공개 서버 WebRTC 검사는 배포 폴더 QA에 기록.
- WebRTC 검사는 같은 PC의 세 프로세스(플레이어 2명·방장 관전자 1명)와 공개 HTTPS 서버로 수행.
- 매치메이킹 서버 프로토콜 10/저장 버전 6 배포 완료. 게임 시뮬레이션 호스트는 방장의 PC를 유지한다.
