# 자원 좌표와 선택 정보

아스는 2×1타일, 테라는 4×2타일입니다. `resource.pos`는 실제 점유 사각형의 지면 중심이며 그림의 높이·돌출 장식은 충돌 크기를 바꾸지 않습니다. `ACCore.resource_size(type)`와 `resource_rect(resource)`가 실제 길 찾기·유닛 충돌에 쓰이는 규격입니다.

정수 좌표가 타일 중심입니다. 아스 중심은 `(n+0.5, m)`, 테라 중심은 `(n+1.5, m+0.5)`에 놓입니다. 4×2 정제 건물의 첫 타일은 `vent.pos-(1.5,0.5)`입니다. `refinery_anchor(resource_or_id)`는 이 정수 앵커를 반환하며, 잘못 정렬된 매장지는 `Vector2.INF`로 거절합니다. `snap_refinery(owner,pos)`는 근처의 유효한 매장지 앵커만 찾고, 실제 건설 명령도 정확히 그 위치인지 다시 검사합니다. 정제 건물의 물리 사각형과 매장지의 사각형은 완전히 같습니다.

자원 스냅샷은 다음 값을 제공합니다.

| 필드 | 의미 |
|---|---|
| `id` | 고갈 뒤에도 유지되는 자원 ID |
| `pos`, `type` | 지면 중심과 `as`·`tera` 종류 |
| `initial_amount` | 지도에서 정한 최초 매장량. 기본 아스 1,500·테라 5,000 |
| `amount` | 현재 시야 안의 남은 양 또는 마지막 관측값. 아직 보지 못했으면 최초 매장량 |
| `visible` | 점유 타일 중 하나 이상이 현재 보이는지 |
| `amount_known` | 남은 양을 실제로 관측한 적이 있는지 |
| `depleted` | 표시할 `amount`가 0인지. 시야 밖 실제 고갈을 새로 알려 주지 않음 |
| `collision_size` | 아스 `[2,1]`·테라 `[4,2]` |

고갈된 아스는 이동 장애물에서 빠지지만 스냅샷에는 남아 있어 선택 상세에서 0을 표시할 수 있습니다. 고갈된 테라는 분출구 장애물을 유지하고 자동 생산은 멈춥니다. 최초 매장량은 채취·고갈 뒤에도 바뀌지 않습니다.

아스 한 노드에서는 한 일꾼만 채굴합니다. 채굴·반납 중인 일꾼끼리의 통과는 허용합니다. 마지막 반납이나 정지 명령으로 통과 자격이 끝나면 충돌을 다시 분리하여, 새로 유휴 상태가 된 일꾼 안에 다른 일꾼이 갇히지 않게 합니다. 본부가 막히면 빈 가장자리 접근점을 다시 선택합니다.

네 시작 지점의 실제 본부 점유 영역과 일꾼 출발점은 `ACMap.start_building_anchor(slot,size)`·`start_worker_positions(slot)`를 사용합니다. 가로로 긴 자원과 5×4 본부까지 좌우·상하 반사하면 같은 좌표에 대응합니다.
