아스테라크래프트 다음 업데이트 통합 계획
작성일: 2026-10-20 / 기준 배포판: v0.5.10
상태: v0.6.0 구현 및 검사 반영. 최종 적용 내역과 검증 기록은 update-progress-v060.txt 및 changes-v060.txt, 배포 상태와 해시는 GitHub v0.6.0 Release와 BUILD_MANIFEST.json을 참고한다.
사용자가 지정한 동작을 우선하며, 제안 능력의 이름·비용·수치·연구 연결은 구현 전 밸런스 설계에서 확정한다.
비행체 시점은 유지한다. HUD는 28번의 공통 규격을 우선하며, 기존 HUD 비율이 맞지 않으면 원본·프레임·필요한 레이아웃을 재제작한다는 사용자 최신 지시를 따른다.

2026-10-20 최신 확정 변경
- 모즙체의 과육 저장/시체 회수 자원 제거. 최대 마나 200, 시작 25, 점진 회복을 사용한다.
- 기본 과즙 치유: 켜진 상태로 생산, 반경 4의 부상 귤 아군 1기 자동 치료. 초당 체력 8/마나 4. 버튼으로 켜기/끄기.
- 군체신경핵 연구 생명 환원: 내 지상 유닛 1기 소모 후 마나 75 회복, 사거리 4, 재사용 20초. 자신/배양체/건물/탑승 유닛/승객이 있는 수송선 제외, 마나 최대치에서는 사용 불가.
- 군체신경핵 연구 개화 촉진: 마나 75, 반경 4의 아군 지상·공중 유닛 공격속도 +25%, 6초 지속, 재사용 18초. 중복 사용해도 배율 중첩 없음. 보호막 기술은 추가하지 않는다.
- 두 기존 과육 소비 기술은 위 구성으로 교체. 세 능력의 새 전용 아이콘·효과 스프라이트도 연결한다.
- 접목충: 아스 100/테라 150으로 인상. 정신 조종은 마나 200을 모아 전부 소비한다. 최대 마나 200은 유지한다.

1. 성능과 장기전
- 인구수 50/100/150/200에서 대기·이동·채굴·전투를 분리 측정.
- 10~15분 이후 5~10 FPS까지 내려가는 현상을 포함해 20분 이상 누적 부하 확인.
- 세 맵·세 종족 비교, 황철 분지를 상대적으로 덜 끊기는 비교군으로 사용.
- 경로 탐색, 밀집 충돌, 채굴 자리 경쟁, 뿌리/안개 갱신, 전투/사망 효과, 리플레이 기록, 메모리 증가를 분리 계측.
- 전장의 안개 패치 이후 끊김이 늘었다는 사용자 제보는 32번의 별도 성능 항목으로 추적하고 실제 원인을 계측해 확인.
- 평균 FPS뿐 아니라 프레임 시간 상위 구간과 순간 멈춤의 지속시간을 비교.
- v0.5.10의 부분 경로 지도 갱신 이후 남은 최초 지도 생성·대군 이동 등의 부하도 확인.

2. 창모드 마우스 문제
- 제목 표시줄 드래그, 창 이동/크기 변경, 비활성화, Alt+Tab 시 강제 마우스 이동이 개입하지 않도록 수정.

3. 모든 연구 건물의 취소와 연구 대기열
- 장갑연구소만이 아니라 세 종족 전체 연구 건물 점검.
- 여러 연구 예약, 순차 진행, 진행 중/대기 중 항목 개별 취소, 자원 반환 처리.
- 이미 완료한 연구나 중복 예약 불가 연구의 중복 실행 방지.
- 완료 직전 취소와 호스트/참가자/관전자 동기화 검증.

4. 혼합 부대 명령
- 야전의무병이 첫 번째여도 전투 병력이 포함된 선택은 공격이동 가능.
- 부대 대표 유닛의 공격 가능 여부로 전체 명령을 막지 않음.
- 비전투 지원 유닛은 이동·치료 역할 수행. 정지/위치 사수도 확인.
- 클릭과 드래그 선택의 판정 기준을 발밑 지면 좌표에서 화면에 보이는 유닛 몸체 중심으로 변경.
- 지상/공중, 크기, 비행 높이, 스프라이트 여백과 확대/축소에 맞는 시각적 중심 사용. 이동·충돌의 지면 기준점은 별도로 유지.
- 겹친 유닛의 클릭 우선순위와 드래그 경계 판정이 보이는 유닛 위치와 일치하는지 검증.

5. 채굴 경로
- 과숙의 심장 6시 30분 본진에서 일꾼 증가에 따른 동선 이상 재현.
- 광물 선택, 본진 반대쪽 접근, 광물 사이 끼임, 자리 경쟁, 반납 지점, 불필요한 재탐색 확인.
- 다른 스타팅과 세 맵 전체로 점검 확대.
- 채굴 중 충돌 무시와 가까운 광물 우선 등 기존 사용자 요구 유지.

6. 건물 버튼과 고유 기능
- 모든 건물의 실제 기능·비용·선행 조건·설명·버튼·취소·진행 표시를 대조.
- 생산/연구/자원/인구/방어/지원 건물 각각 건설할 이유와 고유 역할 마련.
- 역할이 없거나 겹치는 건물의 기능 재설계. 지속 효과 건물은 상태와 효과를 명확히 안내.
- 관련 기술 연구와 핵미사일 생산을 기존 건물 기능 설계에 연결.

7. 귤 본진과 배양체 생산
- 군체모수에서 직접 유닛 생산 명령 대신 '연결된 배양체 전체 선택' 버튼 제공.
- 해당 본진에 연동된 추가배양낭의 배양체도 포함하고 다른 본진 소속은 제외.
- 일반 부대 선택 수 제한 때문에 일부 배양체가 빠지지 않게 처리.
- 배양체별 독립 변태. 본진 공유 생산 대기열 한도를 적용하지 않음.
- 실제 배양체 수·자원·인구 조건에 따라 동시 생산. 연결 소실/복구와 취소 상태 확인.

8. 수송
- 탑승·하차 사운드 추가, 동시 재생 중첩 제어.
- 정보 탭에 탑승 유닛을 칸별 실루엣으로 표시. 빈칸, 점유 용량, 이름 안내.
- 탑승/하차/사망/소유권 변경 시 실제 탑승 정보와 표시 일치.

9. 유닛 방향
- 전체 유닛의 이동/공격 방향과 방향별 스프라이트·좌우 반전 확인.
- 포탑 방향과 차체 방향을 구분하고 기존 비행체 시점 유지.
- 전체 공격 유닛의 무기를 대조해 무기별 공격 동작·발사체·명중 스프라이트를 구분.
- 발톱/창/칼은 휘두르기·찌르기와 타격 효과, 총기는 총구 섬광·탄환·탄착, 포/미사일은 발사·비행·폭발 효과로 표현.
- 과즙/씨앗/가시/덩굴은 각 재질과 형태에 맞는 공격 효과, 광선/마법은 전용 발사·궤적·명중 효과 제공.
- 무기 끝/포구에서 발사되고 대상 몸체에 맞도록 방향별 위치와 깊이 정렬 확인. 지상/공중 및 다른 무기를 쓰는 공격 모드도 구분.
- 공격 준비·타격/발사·회복 동작을 실제 공격 주기와 맞추고, 시각 효과가 별도 피해나 중복 타격을 만들지 않도록 처리.
- 새 공격 효과에도 동시 표시량·재사용·시야 처리를 적용하고 대규모 전투 성능 검증.

10. 근접 포위
- 목표 주변 접근 자리를 나눠 예약하고 빈자리로 우회.
- 앞 병력에 막힌 후방 병력이 계속 같은 자리로 밀지 않도록 개선.
- 이동 표적·대형 표적·좁은 통로에서 재탐색 폭증과 위치 떨림 방지.

11. 방어타워
- 종족별 사거리·탐색 범위·사각지대와 비용 대비 실효성 재검토.
- 실제 공격 판정, 사거리 표시, 정보 수치 일치.

12. 부엉이 건설 범위
- 규율탑의 유효 범위와 건물 전체가 범위에 들어오는지 명확히 표시.
- 본진/규율탑/테라의 범위 예외 유지.
- 테라의 완성 아군 본진 14칸 조건을 별도로 표시.

13. 원본 맵 대칭
- 가장 하얀 맵의 정확한 맵 ID를 먼저 확인하고 원본 지형·자원·스타팅·경사로의 대칭/회전 구성과 비교.
- 원본 의도와 다른 배치만 수정. 원본의 의도적인 비대칭을 임의로 제거하지 않음.

14. 경사로와 절벽
- 눈에 보이는 경사로 폭과 통행 가능한 충돌 폭 일치.
- 대형 유닛, 다수 병력, 양방향 통행 검증.
- 경사로 이외의 절벽을 오르거나 절벽 면에 걸치는 문제 해결.
- 밀림, 포위, 생성, 수송 하차에서도 고저차·정적 충돌 준수.

15. 공격이동 우회
- 지형에 막히면 유효한 경로로 우회해 공격이동 계속.
- 동일 장애물 반복 충돌, 목적지 상실, 잦은 좌우 반전과 재탐색 집중 방지.

16. 유닛 설명과 툴팁
- 역할, 지상/공중 공격 대상, 강점/약점, 비용/인구/시간, 특수능력 안내.
- 장갑별 추가 피해, 업그레이드 후 수치, 생체/기계 분류, 치료/수리 가능 여부 표시.
- 마법/기술의 비용, 사거리, 재사용 시간, 지속시간, 자동 사용, 해금 조건 표시.
- 가시꽃의 공격 대상과 귤박쥐 풀잎 날개 등 설명/현재 설정 불일치 수정.

17. 역할 차별화와 보상 밸런스
- 열등한 유닛의 가격/인구/생산 시간 또는 고유 성능을 보상. 고가 유닛은 비용에 맞는 장점 제공.
- 경장갑/중장갑 속성을 유닛 설계에 맞게 지정. 생체/기계와 방어력 수치는 별도 속성으로 취급.
- 기본 피해와 대경장갑/대중장갑 추가 피해 구분.
- 과도한 공격 주기와 첫 타격 지연 조정. 발당/범위 피해도 함께 조정.
- 동일 자원·동일 인구 및 혼합 병력 교전으로 검증.
- 가시꽃: 지상/공중 공격 유지, 공중 공격력을 더 높게 설정.
- 과즙분사체: 짧은 사거리 유지, 높은 체력과 좁은 범위 공격으로 보상.
- 결계사제: 체력 자동 치료, 야전의무병보다 회복량 대비 높은 에너지 소모.
- 전열사수는 범용, 돌격병은 침투, 방패보병은 정면 유지, 차륜차는 중장갑/대공, 전차는 대지 공성, 이동요새는 전선 거점.
- 껍질발톱은 포위, 후피거수는 돌파 전열, 과숙폭탄은 밀집 경장갑, 덩굴포식자는 이동 방해, 가시꽃은 대공 중심, 귤박쥐는 기동 견제.
- 서약수호자는 전열, 성문궁수는 중장갑 단일 화력, 규율집행관은 통제, 석익병은 근거리 광역, 궤도창은 장거리 관통, 대심판선은 고가 목표 압박.
- 정찰/탐지/수송 유닛도 종족별 비용·기동·생존·운용 차이 부여.

18. 주문과 에너지 공통 규칙
- 주 시전자의 평타 하향: 천문심판관 9→4~5, 접목충 7→3~4는 검토용 수치. 규율집행관도 주문 중심으로 조정.
- 결계사제/모즙체/야전의무병은 기본 공격 없음 유지.
- 기본 능력 하나만 해금, 고위력 추가 능력은 관련 건물 연구 후 사용.
- 연구 완료는 해당 플레이어의 기존/신규 동종 유닛에 공통 적용.
- 자동 치료/탐지/태세 등 기본 기능과 추가 고위력 연구 능력을 명확히 구분.
- 마나/에너지는 최대치 일부만 가진 채 생성되고 시간에 따라 충전. 초기 배치에도 같은 원칙 적용.
- 초기 충전량은 고위력 능력을 즉시 사용할 수 없게 설정. 충전 속도/능력 비용/첫 사용 시점 함께 조정.
- 변태/탑승/정신 조종 등으로 충전 초기화 이득이나 중복 사용이 생기지 않게 처리.
- 제어 효과 무한 중첩/연속 구속 제한, 유효 대상·거리·시야·해금·자원 조건 서버 판정.

19. 마법 유닛 능력안
- 천문심판관: 기본 소규모 천문심판 / 연구 심판 강화·정적의 봉인(단일 적 능력 일시 제한).
- 접목충: 기본 신경 교란(공격 속도 감소) / 연구 정신 조종·위장 탈피(감속/구속 해제와 잠깐 가속, 사용 시 잠깐 노출).
- 규율집행관: 기본 구속 고리 / 연구 규율장(좁은 감속 지대)·행군 칙령(아군 이동 지원).
- 결계사제: 기본 고소모 자동 체력 치료 / 연구 보호 문장(단일 임시 보호막)·정화.
- 모즙체: 기본 마나 자동 치유 / 연구 생명 환원(내 지상 유닛 1기 소모·마나 75 회복)·개화 촉진(주변 아군 공격속도 +25%). 시작 마나 25/최대 200, 과육 자원 제거.
- 최종 연구 연결: 과즙분비샘/군체신경핵/원시과수핵, 천문관측소/황혼기록원/복원성당/대심판성소 등 기존 건물 역할에 맞춰 확정.

20. 바위너구리 기술
- 마법 대신 의무 장비·전자전·기계 운용 기술로 설계.
- 관측 드론: 기본 탐지 / 연구 정밀 스캔.
- 굴착포 전차: 기본 고정 태세 / 연구 준비 동작이 있는 과충전 포격.
- 이동요새: 기본 고정 방어 / 연구 공격을 멈추고 자신을 수리하는 비상 정비.
- 정찰병의 주력 고급 기술은 아래 핵미사일 유도로 변경. 앞선 전자기 교란탄은 확정 능력으로 넣지 않음.
- 야전의무병의 두 추가 기술도 아래 최신안으로 교체. 앞선 응급 처치 제안은 확정 능력으로 넣지 않음.

21. 그림자 정찰병 핵미사일 유도
- 사용자가 지정한 정찰 관련 시설에서 고가 핵미사일을 별도 생산. 기존 전술정보국을 담당 시설로 삼는 설계안.
- 참고: 현재 소스에서 정찰병 자체의 생산자는 전투병영. 전술정보국이 현재 생산자라고 기록하지 않음.
- 기본 은폐 유지. 고급 유도 기술은 연구로 해금하고 완성된 핵 탄약이 있어야 사용.
- 핵 생산 대기열/완료 수량/예약 상태/취소 환불/보유 한도 안내.
- 유도 중 이동·공격 제한, 사망/중단 명령의 취소, 발사 확정 시 탄약 소모. 동일 탄약 중복 예약 방지.
- 경고음·표식·충분한 대응 시간, 폭심/외곽 피해 구분. 실제 피해·범위·가격·생산 시간·아군 피해 규칙은 밸런스 단계에서 확정.
- 관련 연구·생산·유도·명중·중단을 멀티플레이에서 동일하게 처리.

22. 야전의무병 추가 능력 두 개(제안)
- 기본 자동 치료 유지.
- 전투자극주사: 아군 바이오닉 하나의 공격/이동 속도를 잠시 높임. 중복 중첩 방지, 에너지 소모와 재사용 시간 적용.
- 차폐연막: 좁은 지역의 아군이 받는 일반 원거리 공격 피해를 잠시 감소. 근접·마법·핵 공격을 차단하지 않음.
- 두 추가 기술은 야전의료소에서 각각 연구 후 해금. 이름·효과·수치는 설계안이며 검증 후 확정.

23. 다른 종족 대형 유닛 추가 능력(각 1개 제안)
- 후피거수 '외피 강화': 짧은 시간 일반 공격 피해 감소, 전열 돌파 지원.
- 씨앗박격체 '씨앗 산개탄': 다음 포격의 범위 확대, 단일 목표 피해 효율은 감소.
- 대과수 '뿌리 쇄도': 뿌리내린 상태에서 전방 지상에 범위 피해와 짧은 구속. 지형을 변경하거나 절벽을 통과시키지 않음.
- 고대석익병 '석익 충격파': 근거리 부채꼴 지상 공격과 짧은 감속. 강제 밀치기는 사용하지 않는 초안.
- 궤도창 '단열 관통탄': 다음 포격이 목표 방어력의 일부를 무시하는 고소모 단일 타격.
- 대심판선 '천공의 판결': 준비 동작 후 지정 방향에 강한 직선 광선. 범위와 지상/공중 타격은 시각적으로 명확하게 표시.
- 기본 능력 1개 해금 원칙에 맞춰 고위력 추가 기술은 연관 진화/연구 건물에서 해금. 에너지 또는 고유 소모 자원과 재사용 시간 부여.

24. 종족별 사망 스프라이트
- 귤: 과육/주황 귤즙과 지면 웅덩이가 남아 점점 옅어짐.
- 바위너구리 바이오닉: 붉은 피 웅덩이 / 메카닉: 폭발·파편 후 소멸.
- 부엉이: 푸른 불꽃으로 타오른 뒤 빠르게 소멸.
- 크기별 변형, 지면 깊이 정렬, 시야 밖 사망 정보 노출 방지.
- 충돌/이동/건설 판정을 추가하지 않는 시각 효과. 수명과 동시 표시량 제어, 재사용으로 장기전 누적 방지.
- 귤 사망 웅덩이는 시각 효과이며 회수 자원을 만들지 않는다. 모즙체는 마나만 사용한다.

25. 리플레이 수동 저장
- '리플레이 저장' 버튼을 눌렀을 때만 파일로 저장.
- 경기 종료/항복/메인 화면 복귀/종료의 자동 저장 제거. 결과 화면에서도 명시적인 저장 버튼 제공.
- 전체 경기를 저장할 수 있도록 필요한 기록은 메모리에 가볍게 유지하되 과도한 상태 복제/압축 작업 완화.
- 파일 직렬화/압축/쓰기와 성공 알림은 버튼 동작 시 처리. 실패를 성공으로 알리지 않음.
- 저장하지 않고 나가면 리플레이 파일 생성하지 않음. 중복 클릭·파일명 충돌·관전 정보 범위도 검증.
- 저장된 리플레이의 재생과 새로운 능력/연구/장갑/핵/수송 이벤트 기록 일치.

26. 진행 순서와 완료 기준
- 성능 재현·계측 → 이동/충돌/채굴/리플레이 부하 → 조작/명령/취소 → 연구/배양체/건물 기능 → 장갑/밸런스/능력 → 툴팁/범위/수송/사망 연출.
- 새로운 능력과 연출 추가 후 장기전·대규모 전투 성능 다시 비교.
- 세 맵·세 종족, 실제 게임 입력, 호스트/참가자/관전자, 연구 취소·핵 중단·저장 실패 등 예외 검증.
- 세 종족 HUD 공통 규격과 초상화 맞춤/비행체 시점 유지 확인, 실행 파일 빌드, 실제 부팅, 패키지 무결성 검증, GitHub 소스와 배포본 업데이트.
- 구현 완료 항목과 설계만 남은 항목을 명확히 구분해 보고.

27. 본진 상실 후 60초 재건 규칙
- 플레이어가 소유한 살아 있는 완성 본진이 모두 사라지면 60초 재건 제한시간 시작.
- 제한시간 안에 새로운 본진을 완성하면 패배 유예 해제. 건설 시작만으로 제한시간을 초기화하거나 멈추지 않음.
- 본진 없이 60초가 지나면 해당 플레이어 패배 처리. 다른 건물이 남아 있어도 적용.
- 건설 취소/파괴/반복 착공으로 시간을 연장하지 못하게 처리. 본진을 완성해 복구한 뒤 다시 모두 잃으면 새로운 60초 시작.
- 당사자에게 남은 시간과 패배 조건을 명확히 표시하고 호스트/참가자/관전자에 판정과 시간이 일치하도록 동기화.
- 기존 승패 판정과 충돌하지 않게 재건 가능 상태·전체 전멸·항복·팀전 종료 조건을 함께 정리. 적에게 미확인 본진 위치를 노출하지 않음.
- 여러 본진 중 마지막 본진 상실, 정확한 60초 경계, 완성/파괴 동시 발생, 일시정지, 연결 변경 상황 검증.

28. 종족별 HUD 초상화 크기 통일과 맞춤 이미지
- 세 종족의 초상화 내부 표시 영역을 동일한 가로·세로 크기와 비율로 통일.
- 각 종족 프레임 장식의 차이 때문에 실제 표시 면적이 달라지는 문제를 점검하고 공통 내부 규격 적용.
- 확정된 표시 영역의 규격에 맞춰 초상화를 제작·보완하고 얼굴과 주요 형태의 위치·크기를 일관되게 구성.
- 배경까지 표시 영역을 채우고, 늘어짐·불필요한 검은 여백·얼굴/턱/주요 부분 잘림·프레임 침범 방지.
- 유닛/건물 선택, 종족 전환, 창 크기와 해상도 변경에서도 표시 영역과 맞춤 이미지가 정확히 맞는지 검증.
- 기존 HUD 비율이 공통 규격에 맞지 않으면 종족별 HUD 원본·프레임·필요한 레이아웃도 재제작. 기존 비율 유지보다 공통 규격과 정확한 맞춤을 우선한다는 사용자 최신 지시 적용.
- 세 종족의 초상화 표시 면적과 HUD 구성 비율을 공통 기준으로 맞추고 종족별 장식과 분위기를 반영.
- 재제작 시 버튼 기능·클릭 영역·툴팁·수송 정보와 화면 가림 범위를 함께 검증. 재제작 전후 비교 이미지로 변경 사항 기록.

29. 유닛별 스프라이트 프레임 규격 통일과 동작 보강
- 사용자 표현 '스트라이프 수'는 스프라이트 애니메이션 프레임 수로 반영.
- 같은 동작 상태의 프레임 수·방향 수·프레임 배열·재생 기준을 공통 규격으로 정리. 최종 프레임 수는 실제 제작량과 성능을 검토해 확정.
- 대기/이동/공격/채굴/시전 등 동작별 규격을 나누고 프레임이 부족한 유닛은 실제 중간 동작을 제작해 보강.
- 프레임마다 피벗·발 위치·몸체 중심과 크기를 맞춰 움직임 중 위치가 튀거나 흔들리지 않게 처리.
- 이동 속도와 이동 애니메이션, 공격/시전의 타격·발사 시점과 실제 판정을 동기화.
- 이동/정지/공격 전환, 방향 전환·좌우 반전, 비행 날갯짓과 수송 동작의 연결을 확인.
- 프레임/이미지 증가에 따른 텍스처 메모리·로딩·대규모 전투 부하 검증. 기존 비행체 시점 유지.

30. 신규 유닛 선정과 최신 설계
- 바위너구리 화염돌파차: 사용자 선택 반영. 기갑공장 생산의 기동 경장갑 소탕 차량으로 설계.
- 바위너구리 드론 항공모함(가칭 강철둥지 모함): 사용자 지정 구조 반영. 본체 공격 능력 없음, 별도 생산한 작은 전투 드론을 최대 8기 탑재.
- 드론은 자원을 지불해 개별 생산하고 소실 시 재생산. 보유+생산 중 수량이 8기를 넘지 않게 처리. 모함 명령에 따른 출격/공격/복귀와 HUD 8칸 상태 표시 설계.
- 항공모함/드론의 비용·인구·작전 반경·모함 파괴 처리·기술 연구 연결은 밸런스 단계에서 확정. 다수 모함과 드론의 AI/표적/효과 부하 검증.
- 부엉이 신규 지상 중기계는 사용자 최종 선택인 '성좌추격기'로 확정. 석익조형소에서 생산.
- 성좌추격기는 이동하면서 광선을 지속 사격하는 추격 병기. 같은 표적을 계속 공격하면 화력이 상승하고 표적 변경 시 초기화. 상승 상한과 사거리/시야 이탈 처리를 명확히 설계.
- 성좌추격기의 정찰/추격 동작, 몸체 이동과 무기 조준, 단계별 광선 스프라이트를 제작. 중장갑/기계 분류와 비용·인구·최종 수치는 밸런스 검토 후 확정.
- 부엉이 신규 공중 유닛 '성운날개'와 귤 신규 유닛 '심근잠복체/산성낭비룡'은 앞선 제안 단계로 기록. 사용자가 확정한 유닛과 구분.

31. 마법·기술별 신규 전용 스프라이트 제작
- 사용자 명시 지시: 마법이나 기술을 추가할 때 해당 능력별 전용 스프라이트도 새롭게 제작.
- 능력마다 필요한 시전 준비/발동, 발사체/광선/이동 궤적, 명중/폭발, 지속 영역, 버프/약화 표시, 종료/소멸 효과를 구분해 제작.
- 종족 재질·색감·무기/능력 특성을 반영. 치유/정화/구속/은폐/핵 유도/핵폭발/드론 출격/성좌추격기 단계별 광선 등 실제 추가 기능과 연결.
- 범용 효과의 색만 바꾸는 방식에 의존하지 않고 각 능력을 구분할 수 있는 형태·동작·실루엣을 설계.
- 유닛 몸체/손/무기 끝/포구 등 발동 위치, 방향별 피벗, 대상 높이, 지상/공중 깊이 정렬과 실제 효과 범위를 일치.
- 예고·유도·실제 타격·지속시간·중단·종료 프레임을 게임 판정 및 사운드와 동기화.
- 아이콘/툴팁/효과 표시를 대조해 능력 식별 가능성 확인. 동작 프레임 공통 규격과 비행체 시점 준수.
- 시야 밖의 시전/명중/지속 효과로 적 정보가 노출되지 않게 처리. 효과 동시 표시량·수명·재사용·텍스처 부하를 대규모 전투에서 검증.

32. 전장의 안개 패치 이후 끊김 집중 개선
- 사용자 제보: 전장의 안개 패치 이후 발생하거나 심해진 렉과 순간 멈춤을 별도 재현. 안개가 원인이라고 단정하지 않고 변경 전후의 같은 조건을 비교 계측.
- 시야 계산, 탐색 기억, 유닛/건물 가시성 검사, 안개 메시/텍스처 갱신과 업로드, 뿌리 표시/기억, 건물 마지막 관측 정보 갱신을 분리 측정.
- 병력 대이동/탐색, 카메라 이동, 시야 겹침, 뿌리 확장, 다수 적 출현, 관전자 시점 변경, 장기전에서 반복 갱신·할당·전체 캐시 초기화 확인.
- 변한 셀/구역 중심의 갱신, 중복 시야 계산 공유, 표시 캐시와 버퍼 재사용, 화면 갱신 분산으로 특정 프레임에 작업이 몰리지 않도록 개선.
- 실제 시야 판정은 정해진 시뮬레이션 기준으로 유지하고 화면 효과 최적화 때문에 전투 판정이나 네트워크 동기화가 달라지지 않게 검증.
- 미탐색 지역은 숨김, 관측 전 뿌리 숨김, 관측한 뿌리 기억, 마지막으로 확인한 건물의 어두운 위치 정보 유지 등 기존 사용자 안개 요구 준수.
- 건물 기억이 실시간 시야를 제공하거나 숨은 건물 파괴/소유권 변경을 누설하지 않도록 확인.
- 뿌리 아래 본진 표시, 자연스러운 안개/뿌리 경계, 관전자/플레이어/리플레이별 정보 범위도 함께 검증.
- 세 맵·세 종족, 인구수 50/100/150/200, 10~20분 이상 조건에서 평균/상위 프레임 시간·최장 멈춤·CPU/GPU·메모리 사용량을 비교하고 남은 원인을 기록.
